## Flagship project

### ReleaseScope

**AI release-readiness platform for web teams.**

ReleaseScope audits a target URL with Playwright, checks accessibility with axe-core, scores page quality with Lighthouse, and turns technical evidence into a release decision, QA score, and issue-ready backlog.

It is designed as a scalable product for developers, QA engineers, support engineers, and SaaS teams that need clearer release confidence before shipping.

## ReleaseScope ecosystem roadmap

This is the product direction I am building toward:

| Module | Why it is useful |
|---|---|
| **Cloud dashboard** | Track projects, releases, QA score history, trends, owners, and public audit reports |
| **CLI** | Run `npx releasescope audit https://example.com` locally or in CI |
| **GitHub Action** | Audit preview deployments and comment risk directly on pull requests |
| **AI QA Copilot** | Generate edge cases, regression plans, issue descriptions, release notes, and support handoff summaries |
| **Browser Extension** | Connect manual inspection with automated release evidence |
| **EU Compliance Packs** | WCAG, GDPR/cookie checks, security headers, privacy-policy checks, and SaaS launch readiness |
