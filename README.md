## About me

I am a frontend-focused developer with full-stack and IT support experience. I like building tools that solve practical problems: dashboards, QA helpers, content automation utilities, browser extensions, and mobile experiences with real state and user workflows.

My support background helps me think like both a developer and a user: what can break, how to explain it, how to debug it, and how to make a feature easier to maintain.
