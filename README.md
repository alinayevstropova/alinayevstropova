I am a QA Automation Engineer with a full-stack development background, based in Dublin. I specialise in building test frameworks that catch real bugs early — not just ticking coverage boxes.

My developer background means I understand the code I test. I can read a PR, spot risky changes, write a failing test before the fix lands, and wire up a CI pipeline from scratch.
